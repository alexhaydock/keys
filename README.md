# keys

My public keys.

All keys are device-bound. I have moved away from using private keys held on disk in all my setups.

The comment for each key is a three-word reference. Each one maps to an entry in my local Obsidian vault so I can look up the specifics of the key (what device it is enrolled on, etc). I do this since, although it probably wouldn't do much harm, there's no real reason for me to publish my YubiKey serial numbers or which TPMs or enclaves various keys are enrolled in.
